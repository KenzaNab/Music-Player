# Music Player

Full-featured music player with visualizer, playlist, shuffle, repeat and volume control.

> React · TypeScript · Vite · Web Audio API · Canvas API

## Features
- Web Audio API — generates tones for each track
- Canvas visualizer — animated bars sync with music
- Playlist with 5 tracks
- Shuffle and repeat modes
- Volume control with mute
- Click progress bar to seek
- Dark UI with per-track accent colors

## Quick start
```bash
npm install && npm run dev
